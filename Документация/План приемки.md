## 2. Объект приёмки

### 2.1. Что подлежит проверке
1. **Рабочее веб-приложение** (демонстрация в реальном времени в браузере)
2. **Исходный код** (структура, качество, комментарии)
3. **Документация** (полнота пакета: 9 основных документов)
4. **Соответствие требованиям** (функциональным и техническим)

### 2.2. Требования к демонстрации
- **Продолжительность:** 10-15 минут
- **Формат:** Живая демонстрация с двумя браузерами (или двумя устройствами)
- **Сценарий:** Стандартный (Приложение А)
- **Оборудование:** Ноутбук студента + проектор / два устройства в локальной сети
- **Подготовка:** Сервер должен быть запущен до начала демонстрации

### 2.3. Технические требования к демонстрации
```
Требования к сети:
- Все устройства в одной локальной сети
- IP сервера известен (статический или текущий)
- Порт 8000 (Python) или 3000 (Node.js) открыт

Требования к браузерам:
- Chrome 90+ / Firefox 88+ / Safari 14+
- JavaScript включен
- WebSocket поддержка
```
