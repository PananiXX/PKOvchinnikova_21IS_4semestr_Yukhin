## 1. Общие сведения

### 1.1. Наименование системы
**Полное наименование:** QuickChat - Веб-мессенджер для образовательных учреждений  
**Краткое наименование:** QuickChat  
**Кодовое наименование:** WebEduChat

### 1.2. Основание для разработки
Учебный проект по дисциплине "Моделирование программных продуктов" для демонстрации навыков разработки современных веб-приложений с использованием двух технологических стеков.

### 1.3. Назначение разработки
Создание рабочего веб-мессенджера для локальной сети образовательного учреждения с целью изучения:
- Современной веб-архитектуры (клиент-сервер)
- REST API разработки (FastAPI / Express)
- Real-time коммуникации (WebSocket / Socket.io)
- Аутентификации и авторизации (JWT)
- Работы с базами данных (SQLite / MongoDB)
- Адаптивного веб-дизайна (HTML5/CSS3/JavaScript)

### 2.3. Структура базы данных

#### Вариант 1: SQLite (Python)
```sql
-- Таблица пользователей
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    password_hash VARCHAR(200) NOT NULL,
    avatar VARCHAR(255),
    is_online BOOLEAN DEFAULT FALSE,
    last_seen DATETIME DEFAULT CURRENT_TIMESTAMP,
    is_admin BOOLEAN DEFAULT FALSE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Таблица чатов
CREATE TABLE chats (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name VARCHAR(100),
    is_group BOOLEAN DEFAULT FALSE,
    created_by INTEGER NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (created_by) REFERENCES users(id)
);

-- Таблица участников чата
CREATE TABLE chat_participants (
    chat_id INTEGER NOT NULL,
    user_id INTEGER NOT NULL,
    joined_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (chat_id, user_id),
    FOREIGN KEY (chat_id) REFERENCES chats(id),
    FOREIGN KEY (user_id) REFERENCES users(id)
);

-- Таблица сообщений
CREATE TABLE messages (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    chat_id INTEGER NOT NULL,
    sender_id INTEGER NOT NULL,
    content TEXT,
    message_type VARCHAR(20) DEFAULT 'text', -- text, image, file
    file_data TEXT, -- base64 для изображений
    file_name VARCHAR(255),
    file_size INTEGER,
    is_deleted BOOLEAN DEFAULT FALSE,
    reply_to_id INTEGER,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (chat_id) REFERENCES chats(id),
    FOREIGN KEY (sender_id) REFERENCES users(id),
    FOREIGN KEY (reply_to_id) REFERENCES messages(id)
);

-- Индексы для производительности
CREATE INDEX idx_messages_chat_id ON messages(chat_id);
CREATE INDEX idx_messages_created_at ON messages(created_at);
CREATE INDEX idx_users_online ON users(is_online);
```

### 5.2. WebSocket интерфейсы

#### Вариант 1: Python (Native WebSocket)
```javascript
// Подключение
const ws = new WebSocket(`ws://${serverIp}:8000/ws?token=${token}`);

// События
ws.onopen = () => {
    console.log('WebSocket подключен');
    ws.send(JSON.stringify({
        type: 'ping'
    }));
};

// Получение нового сообщения
ws.onmessage = (event) => {
    const data = JSON.parse(event.data);
    
    switch(data.type) {
        case 'new_message':
            // Новое сообщение в чате
            addMessageToChat(data.message);
            break;
            
        case 'message_read':
            // Сообщение прочитано
            updateMessageStatus(data.messageId, 'read');
            break;
            
        case 'user_status':
            // Изменение статуса пользователя
            updateUserStatus(data.userId, data.isOnline);
            break;
            
        case 'typing':
            // Кто-то печатает
            showTypingIndicator(data.userId, data.chatId);
            break;
            
        case 'pong':
            // Ответ на ping (keep-alive)
            break;
    }
};

// Отправка сообщения о печати
ws.send(JSON.stringify({
    type: 'typing',
    chatId: 1,
    isTyping: true
}));
```

#### Вариант 2: Node.js (Socket.io)
```javascript
// Подключение
const socket = io(`http://${serverIp}:3000`, {
    auth: { token },
    transports: ['websocket']
});

// События подключения
socket.on('connect', () => {
    console.log('Socket.io подключен');
    socket.emit('join_chat', { chatId: 1 });
});

// Получение нового сообщения
socket.on('new_message', (message) => {
    addMessageToChat(message);
});

// Статус пользователя
socket.on('user_status', (data) => {
    updateUserStatus(data.userId, data.isOnline);
});

// Кто-то печатает
socket.on('user_typing', (data) => {
    if (data.isTyping) {
        showTypingIndicator(data.username);
    } else {
        hideTypingIndicator();
    }
});

// Сообщение прочитано
socket.on('message_read', (data) => {
    updateMessageStatus(data.messageId, 'read');
});

// Отправка события печати
socket.emit('typing', {
    chatId: 1,
    isTyping: true
});
```

## 6. Требования к безопасности

### 6.1. Аутентификация и авторизация
1. **JWT токены** с временем жизни (24 часа)
2. **Refresh tokens** для обновления сессии
3. **Хеширование паролей** (bcrypt, 12+ раундов)
4. **Защита от brute-force** (лимиты на попытки входа)
5. **Валидация email** (формат, уникальность)

### 6.2. Защита данных
1. **SQL/NoSQL инъекции:** ORM/ODM защита (SQLAlchemy, Mongoose)
2. **XSS атаки:** Экранирование вывода, CSP заголовки
3. **CSRF:** JWT в заголовках, не в cookies
4. **CORS:** Ограничение доменов
5. **HTTPS:** Рекомендуется в продакшене

### 6.3. Конфиденциальность
1. **Пароли** никогда не передаются в открытом виде
2. **JWT токены** хранятся в localStorage (или HttpOnly cookies)
3. **Изображения** проверяются на тип и размер
4. **Логи** не содержат паролей и токенов
5. **Удаление сообщений** для себя и для всех

## 8. Ограничения системы

### 8.1. Технические ограничения
1. **Работа только в локальной сети** (нет интернета)
2. **WebSocket требует постоянного соединения**
3. **MongoDB требует больше ресурсов** (вариант 2)
4. **SQLite не поддерживает репликацию** (вариант 1)
5. **Нет кластеризации** (учебный проект)

### 8.2. Функциональные ограничения
1. **Нет видеозвонков** (только текст и изображения)
2. **Нет аудиосообщений** (планируется)
3. **Нет push-уведомлений** (только WebSocket)
4. **Нет E2E шифрования** (планируется)
5. **Нет ботов и интеграций**

### 8.3. Браузерные ограничения
1. **localStorage** ограничен 5-10 MB
2. **WebSocket** может обрываться на мобильных сетях
3. **Максимальный размер файла** зависит от браузера
4. **CORS** требует правильной настройки сервера
