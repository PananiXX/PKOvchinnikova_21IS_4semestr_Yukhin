## 1. Быстрый старт

### Что вам понадобится
- Компьютер, ноутбук, планшет или смартфон
- Современный браузер (Chrome, Firefox, Safari, Edge)
- Подключение к локальной сети образовательного учреждения
- IP-адрес сервера QuickChat (сообщит преподаватель или администратор)

### Основные шаги за 1 минуту
1. Откройте браузер и введите адрес сервера: `http://[IP-сервера]:8000` (Python) или `http://[IP-сервера]:3000` (Node.js)
2. Зарегистрируйтесь (email + пароль)
3. Войдите в систему
4. Выберите собеседника из списка контактов
5. Напишите сообщение и нажмите Enter!

## 2. Как запустить QuickChat

### Для студентов (пользователей)

**Вам не нужно ничего устанавливать!**

1. Убедитесь, что ваше устройство подключено к Wi-Fi образовательного учреждения
2. Откройте любой браузер (Chrome рекомендуется)
3. В адресной строке введите адрес сервера:
   - **Если сервер на Python:** `http://192.168.0.100:8000` (адрес может отличаться)
   - **Если сервер на Node.js:** `http://192.168.0.100:3000`

> ⚠️ **Важно:** Точный IP-адрес сервера сообщит преподаватель или администратор

### Для администратора (запуск сервера)

**Python (FastAPI) версия:**
```bash
# 1. Установка Python (если не установлен)
# Скачайте с python.org

# 2. Установка зависимостей
pip install fastapi uvicorn sqlalchemy python-jose passlib websockets

# 3. Запуск сервера
uvicorn main:app --host 0.0.0.0 --port 8000

# 4. Готово! Сервер доступен по адресу:
# http://[IP-компьютера]:8000
```

**Node.js (Express) версия:**
```bash
# 1. Установка Node.js (если не установлен)
# Скачайте с nodejs.org

# 2. Установка зависимостей
npm install express socket.io jsonwebtoken bcryptjs mongoose

# 3. Запуск MongoDB (если используете)
# docker run -d -p 27017:27017 mongo

# 4. Запуск сервера
npm start
# или
node server.js

# 5. Готово! Сервер доступен по адресу:
# http://[IP-компьютера]:3000
```

## 3. Регистрация и вход

### Страница входа

```
┌─────────────────────────────────────┐
│            QuickChat                │
├─────────────────────────────────────┤
│                                     │
│  ┌───────────────────────────────┐  │
│ │           Вход                 │ │
│  ├───────────────────────────────┤  │
│  │ Email:                        │  │
│  │ [________________________]    │  │
│  │                               │  │
│  │ Пароль:                       │  │
│  │ [________________________]    │  │
│  │                               │  │
│  │    [  Войти  ]                │  │
│  │                               │  │
│  │ Нет аккаунта?                 │  │
│  │    [Зарегистрироваться]       │  │
│  └───────────────────────────────┘  │
│                                     │
└─────────────────────────────────────┘
```

### Регистрация нового пользователя

1. Нажмите **«Зарегистрироваться»**
2. Заполните поля:
   - **Имя пользователя** (например, `ivan.petrov`)
   - **Email** (например, `ivan@edu.ru`)
   - **Пароль** (минимум 6 символов)
3. Нажмите **«Создать аккаунт»**
4. При успешной регистрации вы автоматически войдете в систему

### Вход в систему
1. Введите Email и пароль
2. Нажмите **«Войти»**
3. Если данные верны, откроется главная страница чата

## 5. Общение в чатах

### Личные сообщения (1 на 1)

**Как начать диалог:**
1. На левой панели выберите пользователя из списка
2. Откроется окно чата с этим пользователем
3. Напишите сообщение в поле ввода
4. Нажмите **Enter** или кнопку **➤**

**Как понять, что сообщение доставлено:**
- ✓ - сообщение доставлено на сервер
- ✓✓ - сообщение прочитано собеседником

### Пример диалога

```
Иван: Привет, как дела?                      14:30 ✓
Мария: Всё отлично! А у тебя?                14:31 ✓✓
Иван: Тоже хорошо. Готовишь проект?          14:32 ✓✓
Мария: Да, уже заканчиваю                    14:33 ✓
```

### Индикатор "печатает..."
Когда собеседник начинает набирать сообщение, вы увидите:
```
🟢 Мария печатает...
```

## 6. Отправка изображений

### Как отправить изображение
1. Откройте чат с нужным пользователем или группой
2. Нажмите кнопку **📎** (скрепка) рядом с полем ввода
3. Выберите источник:
   - **Выбрать файл** - открыть проводник
   - (на мобильных) **Камера** - сделать фото
   - (на мобильных) **Галерея** - выбрать существующее
4. Выберите изображение (до 5 МБ, форматы JPG, PNG, GIF)
5. Нажмите **«Открыть»**
6. Изображение автоматически отправится в чат

### Просмотр изображений
- Изображение отображается прямо в чате
- Нажмите на изображение для просмотра в полном размере
- На мобильных можно увеличить жестом (pinch-to-zoom)

### Пример медиа-сообщения

│ Мария отправила изображение     │
│ 14:35                           │
│ ┌─────────────────────────────┐ │

│ │                             │ │
│ │       (изображение)         │ │
│ └─────────────────────────────┘ │

## 7. Групповые чаты

### Создание группы
1. На левой панели нажмите **«➕ Новый чат»**
2. Выберите **«Создать группу»**
3. Введите название группы (например, «21ИС-24 Проект»)
4. Выберите участников из списка контактов
5. Нажмите **«Создать»**

### Добавление участников
1. Откройте групповой чат
2. Нажмите на название группы вверху
3. Выберите **«Добавить участников»**
4. Отметьте нужных пользователей
5. Нажмите **«Добавить»**

### Участники группы
- Создатель группы автоматически становится администратором
- Администраторы могут добавлять и удалять участников
- Все участники видят историю сообщений группы

### Пример группового чата

## 8. Управление сообщениями

### Удаление своих сообщений

**Как удалить сообщение:**
1. Наведите курсор на свое сообщение (десктоп)
2. Нажмите на три точки **⋮** или сделайте долгое нажатие (мобильные)
3. Выберите **«Удалить»**
4. Подтвердите действие

**Варианты удаления:**
- **«Удалить для себя»** - сообщение исчезнет только у вас
- **«Удалить для всех»** - сообщение исчезнет у всех участников (только для своих сообщений)

### Результат удаления
```
┌─────────────────────────────────────┐
│ Иван: Привет!                 14:30 │
│                                     │
│ [Сообщение удалено]           14:31 │
└─────────────────────────────────────┘
```

### Ответ на сообщение (если реализовано)
1. Наведите на сообщение → **«Ответить»**
2. Введите ответ
3. Исходное сообщение процитируется

```
┌─────────────────────────────────────┐
│ Иван: А где собрание?               │
│                                     │
│ Вы: [Ответ Ивану]                   │
│     В 215 аудитории                  │
└─────────────────────────────────────┘
```

## 9. Статусы пользователей

### Значения статусов

| Статус | Индикатор | Значение |
|--------|-----------|----------|
| **Онлайн** | 🟢 Зеленый | Пользователь в сети и активен |
| **Офлайн** | ⚫ Серый | Пользователь не в сети |
| **Печатает** | 🟢 + "печатает..." | Активно набирает сообщение |

### Как обновляются статусы
- Статус обновляется автоматически каждые 10 секунд
- При входе в систему статус становится 🟢
- При закрытии вкладки/браузера статус становится ⚫ через некоторое время

## 10. Решение проблем

### Не открывается страница QuickChat

| Проблема | Решение |
|----------|---------|
| **Неверный адрес** | Проверьте IP-адрес сервера у преподавателя |
| **Сервер не запущен** | Сообщите преподавателю |
| **Нет подключения к сети** | Подключитесь к Wi-Fi учреждения |
| **Брандмауэр блокирует порт** | Обратитесь к администратору |

### Не удается войти

| Проблема | Решение |
|----------|---------|
| **Неверный email/пароль** | Проверьте раскладку, Caps Lock |
| **Пользователь не найден** | Зарегистрируйтесь заново |
| **Сервер недоступен** | Проверьте подключение к сети |

### Сообщения не отправляются

| Проблема | Решение |
|----------|---------|
| **Нет выбранного чата** | Выберите собеседника слева |
| **Проблемы с сетью** | Проверьте Wi-Fi |
| **Сервер перегружен** | Подождите и попробуйте снова |
| **WebSocket отключился** | Обновите страницу (F5) |

### Изображения не загружаются

| Проблема | Решение |
|----------|---------|
| **Файл слишком большой** | Используйте изображение до 5 МБ |
| **Неподдерживаемый формат** | Используйте JPG, PNG или GIF |
| **Медленная сеть** | Подождите, файл загружается |

## 11. Частые вопросы

### Как сменить пароль?
В текущей версии смена пароля не реализована. Обратитесь к администратору.

### Сколько пользователей может быть в чате?
- Личные чаты: 2 человека
- Групповые чаты: до 500 участников

### Где хранятся сообщения?
Все сообщения хранятся на локальном сервере учебного заведения. Данные не передаются через интернет.

### Могу ли я использовать QuickChat с телефона?
Да! QuickChat полностью адаптирован для мобильных устройств. Просто откройте браузер на телефоне и введите адрес сервера.

### Нужен ли интернет для работы?
Нет, QuickChat работает в локальной сети. Интернет нужен только для первоначальной загрузки страницы.

### Как выйти из аккаунта?
Нажмите на свое имя в правом верхнем углу → выберите **«Выйти»**.

### Почему я не вижу некоторых пользователей?
Возможные причины:
- Пользователь еще не зарегистрирован
- Пользователь офлайн
- Техническая проблема (обновите страницу)

### Можно ли удалить группу?
Только создатель группы может удалить группу через настройки.

## Приложение: Техническая информация

### Системные требования

**Для сервера (Python версия):**
- ОС: Windows 10/11, Linux, macOS
- Python 3.8 или выше
- 512 МБ RAM
- 100 МБ свободного места

- **Изображения:** JPG, JPEG, PNG, GIF (до 5 МБ)
